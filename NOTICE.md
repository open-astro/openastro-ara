ARA makes no functional changes to Accord; the only in-repo modification is the vendored `Accord.Imaging` source tree (see "Bundled / vendored source" below), whose sole edit is a whole-solution `dotnet format` reformat (commit `7c66a58f0`, 288 files) applied for analyzer/warnings-as-errors compliance — stylistic only, no algorithm or API changes, all upstream license headers left intact.

Complete corresponding source for the patched build is published at [`open-astro/stellarium-web-engine`](https://github.com/open-astro/stellarium-web-engine) (tag `ara-v1`). See `client/openastroara_client/assets/stellarium/README.md` for the full AGPL §13 disclosure + provenance. (Aladin Lite was removed with the #611 planetarium pivot and is no longer bundled.)

## Sky-data catalogs

The org **redistributes unmodified snapshots** of these catalogs from [`open-astro/sky-data`](https://github.com/open-astro/sky-data) (commit-pinned, so they survive upstream repo deletion; that repo's `CATALOG-SOURCES.md` carries the full attribution + provenance pins). Two distributions:

- **Bundled with the client** (`client/openastroara_client/assets/catalogs/`, conveyed inside every client binary since #1105 so search, Tonight's Sky and the planetarium's Catalogs overlays work with no server): the deep-sky catalogs below except HYG.
- **Daemon Data Manager packages** (`.deb` seed copies + on-demand downloads; §36): the same deep-sky catalogs plus HYG, for the daemon's own endpoints and overlays.

Credited here per their terms:

- **HYG star database** ([Astronomy Nexus / David Nash](https://www.astronexus.com/hyg), **CC BY-SA**) — the named-star catalog (Hipparcos + Yale Bright Star + Gliese). Snapshot byte-identical to the archived upstream GitHub repository's `hygdata_v40.csv.gz`. Daemon package only — the client's planetarium draws stars from the Stellarium engine's own data.
- **OpenNGC** ([Mattia Verga](https://github.com/mattiaverga/OpenNGC), **CC BY-SA 4.0**) — the NGC/IC deep-sky object catalog. Snapshot byte-identical to the upstream repository's commit-pinned `NGC.csv`. Bundled with the client and a daemon package; redistributed unmodified under the same licence, with this attribution.
- **Sharpless (Sh2), Lynds dark nebulae (LDN), Barnard dark objects, van den Bergh reflection nebulae (vdB), Abell planetary nebulae, Arp peculiar galaxies** — VizieR (CDS, Strasbourg Observatory, France) TSV exports of the published catalogues (Sharpless 1959 ApJS 4, 257; Lynds 1962 ApJS 7, 1; Barnard 1927 via Dobek 2011; van den Bergh 1966 AJ 71, 990; Acker et al. 1992 SECGPN; Arp 1966 ApJS 14, 1 / Webb 1996), normalised to the OpenNGC column layout in `open-astro/sky-data`. VizieR data may be reused with attribution to the original papers and to CDS ([licence](https://cds.unistra.fr/vizier-org/licences_vizier.html)). Bundled with the client and daemon packages.
- **Galactic Wolf-Rayet Catalogue** ([P. Crowther, University of Sheffield](http://pacrowther.staff.shef.ac.uk/WRcat/); Rosslowe & Crowther 2015, MNRAS 447, 2322) — 717 Galactic WR stars, positions/photometry/spectral types as published on the catalogue site, normalised to the OpenNGC layout. Bundled with the client and a daemon package, credited to the catalogue and its per-row references.

## Online imagery (not bundled)

- **DSS2 colour sky survey via CDS hips2fits** (`alasky.u-strasbg.fr`, CDS Strasbourg Observatory; the Digitized Sky Survey is © AURA/STScI and the original observatories) — the target previews in Plan my night and Tonight's Sky are cutouts fetched on demand from this service and cached under app support; the planetarium's optional "DSS2 sky survey" layer streams the same survey as HiPS tiles. Nothing is redistributed; each request is for the target being planned. Credit: "Digitized Sky Survey (DSS2), STScI/AURA, via CDS hips2fits". (A setting to disable the fetch is tracked as a follow-up.)
