### Fixed (Simple Mode)
- **The rig's sensor is no longer set to 0 when the app connects** (#2041): Simple Mode filled an empty aperture and focal length from the mount and saved the whole optics section. When two optics reads overlapped at connect, it saved its empty defaults with the mount's two values, so the sensor width, height and pixel size went to 0 and the Rig setup asked for the optics again. The rig already fills empty mount optics (#1994) and the sensor from the main camera, so the app now only reads the optics again after a mount or camera connect and never writes them on its own. The aperture and focal length wheels in Settings › Rig now save only after the optics were read from the rig.
- **Set up optics stays in Simple Mode** (#2041): the button in the Rig setup sheet and in the Settings › Rig header opened the full UI's Optics panel. It now opens Simple Mode's Settings › Rig at the telescope rows, which show the main camera's sensor and pixel size read only, filled in when the camera connects.
