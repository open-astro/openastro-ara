### Changed (equipment)

- **The mount moves onto the shared device lifecycle, and the fault ladder waits for a clean read before it calls any device recovered** (#1696): the telescope now connects, refreshes, trips on a lost connection and records the user's connect or disconnect through the same lifecycle module as the other eight devices, so a mount you disconnected by hand is left alone by recovery. After a reconnect the fault ladder counts the mount, Rotator, Dome, FilterWheel, Focuser, FlatDevice, ObservingConditions, SafetyMonitor or Switch as recovered only once a refresh has read it cleanly, not as soon as it answers Connected; each later attempt reconnects a device that is still Connected without a clean read instead of waiting on it. A Rotator or Dome driver that does not implement its essential read (Position, Slewing) still counts as clean. The mount's position read (RA/Dec) now counts as its essential read: a mount whose position read keeps failing raises a degraded warning and is not called recovered.
