### Fixed (polar alignment)
- **The saved RA motor direction is kept per mount, not under a blank driver name** (Polar Align, #2167): Ara never read the mount driver's name or version, so the 0.5° direction test was saved for the driver `""` and every mount shared it. It is now saved for the mount's identity (its Alpaca unique id, else its name, the same key as its clearance) and its driver version when the driver reports one, so a new driver version still tests again. A direction saved before this fix stands for no mount: the next motor start tests it once more. Settings › Imaging › Polar align › RA motor direction shows the mount it was tested on, and the log names it. `polar_align_motor_direction` has `mount_key` in place of `driver_info`.
