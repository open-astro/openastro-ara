### Fixed (guider)

- **Losing the guider mid-frame stops the frame and brings guiding back** (#2169): when the guider link drops while guiding, the light frame in progress now stops at once instead of finishing unguided, and it is not saved or counted. The run pauses, and once the guider reconnects Ara starts guiding again and waits for it to settle before the run resumes and takes the frame again, instead of waiting for the next dither. If guiding does not restart, the run stays paused and a notice says so. A lost guide star works the same way, as before, and darks and bias now always finish.
