### Changed
- **§50/§54 — two silent-failure fixes in Stats and Support.** The Best Frames list no longer shows rows the server sent without a frame id (they were unusable and will matter more when per-frame drill-down lands); and the daemon-log viewer now surfaces an error when the server answers with something other than a log list, instead of silently showing an empty log.
- **§39 — the calibration sessions list stays fast on a big catalog.** Building a page of sessions used to run five database queries per session; it now runs six per page regardless of size, and paging switched to a keyset cursor — so a new session landing while you scroll can no longer make a session repeat or vanish at a page boundary. Old page links keep working.
- **§54 — log and bug-report downloads stream to disk instead of through memory.** Downloading the daemon log or a bug-report bundle used to pull the whole file into WILMA's memory before the save dialog wrote it out. The flow is now destination-first: pick where to save (a folder picker; the file name auto-uniquifies instead of silently overwriting), then the download streams to that path chunk by chunk — memory stays flat however large the log or bundle has grown, which also clears the path for future mobile targets.
- **§29.9 — tailing the daemon log no longer reads the whole file.** The logs panel's tail used to scan every byte of each log file front-to-back just to show the newest 200 lines — on a long session's multi-megabyte day-log, that's a lot of reading for a screenful. The tail now reads backwards from the end of the file and stops the moment it has enough matching lines, so it touches only the file's final chunks regardless of how big the log has grown. Filters (level, substring) and ordering behave exactly as before.
- **§50 — the Stats dashboard's tiles now fit your window.** The Overview and Achievements tiles (and the milestone badges) were a fixed 200 px, so a wide window wasted the right half of every row and a narrow one left awkward gaps. Tiles now share each row edge-to-edge — the column count adapts to the window (down to one full-width column on a narrow pane), with a cap so a lone tile on a wide screen doesn't balloon.
- **Docs reorganized under `docs/`.** `RUNNING.md`, `DEPLOY.md`, and `RELEASE_NOTES.md` moved from the repo root into `docs/` alongside the user guide; cross-references updated. The release notes' stale "still placeholders" list was refreshed to match reality (§64 Live View, §36 sky-data Data Manager, and §43 backup have shipped; §45 polar alignment, §44 backup stream, and DSLR RAW remain pending). `NOTICE.md` stays at the root next to `LICENSE.txt` — packaging (`build-deb.sh`, the `.deb` copyright file) references it there.
- **The daemon's documented install path is the apt.openastro.net APT repository** (maintainer decision 2026-07-07): `docs/DEPLOY.md`'s quick start now adds the OpenAstro apt repo (§34.1 gpg key + sources list) and installs/updates `openastroara-server` through apt, replacing the GitHub-Releases `.deb` download flow; the WILMA client still ships from GitHub Releases (§75).
- **`design/` indexed and decluttered.** New `design/README.md` (what each doc is, how it's maintained, and where "what's left" authoritatively lives); the fully-resolved design-phase gap tracker (`GAPS-ARA.md`) and the obsolete June agent-handoff snapshot (`HANDOFF.md`) moved to `design/archive/` with banners (CI's sanity gate now checks `design/README.md` instead); `PORT_TODO.md` split into open-items-on-top / done-archive-below halves (verbatim block moves); `PORT_PROGRESS.md`'s layered stale "Current" section replaced with an accurate snapshot, the old bullets preserved under Completed.
