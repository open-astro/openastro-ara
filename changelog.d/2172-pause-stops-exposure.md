### Changed
- **Pause stops the frame being taken** (#2172): Pause now stops the exposure in progress at once (light, dark or bias) instead of letting it run to the end, so a 5-minute frame no longer keeps the camera busy for up to 5 minutes. The stopped frame is not saved or counted, and Resume takes it again from the same place in the plan, with the usual re-center. A flat set and a meridian flip still finish first. Guiding keeps running while the run is paused. To keep the frame, use the new **Pause after this frame**: a button under the plan in Simple Mode and a run button next to Pause on the Run tab. Stop after frame still saves its frame. The daemon API takes an optional `{"after_frame": true}` body on `POST /sequences/{id}/pause`; an older daemon pauses after the frame either way.
