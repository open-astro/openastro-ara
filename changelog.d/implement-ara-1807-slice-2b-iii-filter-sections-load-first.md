### Fixed

- **The filter set, the filter wheel slot labels and the filter wheel policy load from the rig before they save** (#1807): Settings. A Save that was never loaded, or that follows a failed load, now writes nothing and says why; a reply from the rig that lacks a setting, names an unknown filter kind or has no slot labels counts as a failed load instead of filling in a default. Before, a slot edit after a failed load could overwrite every other slot name on the rig with the reference eight. A copy another device saved in between is refused and the panel offers Reload. A rig or profile change sends the three back to not loaded. The offline cache fills the filter set for planning only and is never saved; with no rig the panels say so instead of showing that copy. The labels reload when the wheel reports its slot names, not when it connects.
