### Changed (polar alignment)
- **Polar Align always turns RA with the mount's motor: there is no manual mode** (#2170): the hand-turn mode is gone before any release shipped it, as Ara is built to automate a computer-controlled equatorial mount. No screen asks you to turn RA by hand, and a mount that cannot turn its RA axis by motor speed cannot run Polar Align. API: the `hand_turn` field on `POST /equipment/polaralign/start` is gone (a request that still sends it is a plain motor start), with `hand_turn_available`, `hand_turn_wait`, the `polar_align.hand_turn` event, the `hand_turn_too_far` reason and the `polar-align-clutch-turned` refusal.
