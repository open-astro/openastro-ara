### Added (Guider, Simple Mode)

- **The calibration text shows how far each leg has to go** (issue #1895): while the guider calibrates, Simple Mode's Guider pill and the Plan pill's leg, the guiding strip, the run dashboard's Guider line and the Simple Mode preview panel read "West step 3 · 11.9 of 25 px" instead of "West step 3 · 11.9 px". The daemon reads the guider's own calibration distance once per calibration run and sends it as `calibration_target_px` in the guider state (null outside calibrating); a guider that reports none, or a refused read, keeps today's text. Ara adds no setting. The text is in English and Brazilian Portuguese ("11.9 de 25 px"). A screen reader reads the pill's whole text on focus ("Guider, Calibrating, West step 3, 11.9 of 25 px"), and does not announce each step.
