### Changed (rig)
- **One answer to "is the rig busy"** (#2141): the daemon asked this in eight ways, and a run whose catalog session failed to open, an aborting run, polar alignment and centering were each missed by some of them. Now one register answers every check: a storage change, a stats catalog rebuild, filter-offset calibration and the Bahtinov readout are refused during any run, a profile switch is refused during an aborting run, Preflight lists an aborting run as running, and restart when idle and a profile switch also wait for polar alignment and centering. A refusal names what is running ("polar alignment is running").
