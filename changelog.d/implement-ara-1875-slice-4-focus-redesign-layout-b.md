- **Focus is the Autofocus panel, with Tools rows** (#1875): Focus by hand (Bahtinov) and Filter offsets are Tools rows under Autofocus, each with a status pill ("Not started", "2 to measure", "No filter wheel") and a button, that open in place with a Back arrow; the V-curve is shorter so the panel fits an iPad without scrolling; the Auto / Manual / Offsets row and Focus's Info toggle are gone.
