### Changed (rig)
- **Every routine on the rig is in one register now** (#2143): End Night, filter-offset calibration, autofocus, the Bahtinov readout, guide-camera focus, the rotation readout, Live View and a disk-to-disk storage copy join the Rig Occupancy register. Emergency Stop now ends all of them through one rule, including End Night, the rotation readout, Live View and a storage copy, which it did not stop before. The safety park and the fault park end End Night. A step that does not stop in time is named in the result. Busy checks also wait for these routines: for example, a storage rescan waits for a copy, and a profile switch waits for Live View. A refusal says what is running ("Live View is running").
