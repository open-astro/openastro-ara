### Added

- **The OS disk's other partitions can be mounted, but never erased** (daemon and root helper, #1769): `GET /storage/devices` now says per device `system_disk_level` (`none`, `os_partition` for the partition holding `/` or `/boot*` and its ancestors, `os_disk_data` for any other partition on that disk) and `media_kind` (`emmc`, `nvme`, `sd`, `unknown`); `is_system_disk` stays true for both levels. `POST /storage/configure` with `format: true` on either level answers 422 `refused` / `system_disk` before the erase is noted, and `configure-storage.sh` refuses the OS partition in every mode but the OS-disk data partition only for an erase. The client change follows in a later PR.
