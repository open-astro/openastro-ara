Polar Align Start card: Advanced row proposed

Advanced Mode, Polar Align, idle (before Start). A collapsed Advanced row holds the four routine knobs: Home start, Check step, Coarse exposure, Seed rotation. They edit the same Polar Align Routine settings as the Settings panel. Controls stay hidden until the section has loaded. Each edit saves at once; a failed save puts the field back to the rig's value. Pick a layout and a state, then try it: type 4 in Seed rotation, tick Fail the next save, or flip Routine running. Recommended: A.

Same place, one knob per line, name left and control right, like the Settings panel rows. Easiest to scan and match with Settings, but about twice as tall.

C · Opens a popover

The card never grows: the row opens a floating box over the Start card. Keeps the Start buttons fixed, but covers the card, and a popover is harder to use on a phone and with a keyboard.
