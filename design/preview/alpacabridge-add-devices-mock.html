Add your devices: AlpacaBridge first-time setup (#1580)

A fresh rig has an AlpacaBridge with no devices. This mock shows the whole flow in the wizard's Connect screen (Full UI) and in Simple Mode's Settings › Devices. Pick the mode and the step. The form is generated from the catalog sample at the bottom of this file, the way the client would build it from AlpacaBridge's devicecatalog. Nothing here talks to a rig.

Offered only when the catalog readsThe action shows only when GET /equipment/alpacabridge/catalog returns drivers. A server that is not AlpacaBridge, or one too old for the catalog, gets today's message and no button (reachability stays the only gate, §68.1).
Which field the attached camera fillsserialNumber and cameraName. They are what AlpacaBridge's own web picker saves, so the entry binds by serial and survives a renumber. cameraIndex and cameraId (roles EnumerationIndex and DeviceId) stay behind "Enter the index by hand".
Found on this rigThe list is the first thing on an empty rig. Today only ZWO cameras can be listed (GET /equipment/alpacabridge/cameras, from GET /management/v1/attachedcameras?vendor=zwo). A device already configured (same serial, or same driver and port) is not a row. A row with a required field that has no default and no detected value says "Needs details"; its form opens when Add selected reaches it. Add selected sends one add per row, one after the other.
Needs AlpacaBridge detection endpoint (not built). The EAF, EFW and mount rows are drawn from a future endpoint that also lists focusers, filter wheels and mounts on a serial adapter. Today AlpacaBridge lists none of them. A serial auto-detect catalog entry is never drawn as "found": only gear a lister really reports.
Same flow, two looksOne shared flow. Simple Mode keeps its own look (frosted sheet, 48 pt targets, no link to the Full UI). It is the empty state of Settings › Devices, reached from "No devices connected".

Form rules shown: defaults filled in, required fields marked and checked before Add, number range enforced, enum as a choice list, appliesWhen shows or hides a field, nested fields as a group, secret obscured, an unknown field type falls back to a text field. Switch Driver to see each.
