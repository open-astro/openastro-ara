Simple Mode, layout C (ALP-4810): the frame fills the screen; a status strip on top; the attention banner centred under it when something needs you; a right column of Next frame, controls and Emergency Stop, all 168 px wide; a bottom row of guiding, the mode switcher (Preview · Polar align · Focus · Target · Run) and Stop, all 56 px tall. One 16 px inset and 10 px corners throughout. Click the image to hide the panels; Emergency Stop and any alert stay. "Simple: Run plan" shows the quick plan builder. Click a mode on the switcher (Preview, Polar align, Focus, Target, Run) to see its screen; the buttons above show Run plan, Night done and No rig.

State-Only Colour

An accent appears only when it means a state: a dot, a state chip, a destructive action.

Night mode removes hue, so states must differ by brightness too. Left: normal. Right: the app's night filter.

Steady Digits

Every live number uses tabular figures, so a countdown never shifts its neighbours.

No-Glow

No shadows. Surfaces separate by a 1 px hairline and a grey step. Simple Mode's overlays are the one translucent surface.

One Ramp

New screens use the shared type sizes, not per-widget 11/12/13 px styles.

Two Densities

Full UI dense. Simple Mode and phones roomy and image-first. Same colours, rules and Emergency Stop.
