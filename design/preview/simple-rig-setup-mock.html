Rig setup: where it lives, and how its fixes read

Mock for feedback items 1 and 2. Same example rig everywhere: Site and Main camera & telescope are missing, Guide scope and Guider calibration are done. Colours are Ara's own tokens (amber = needs attention, green = done, blue = primary).

1 · Settings › Rig header

Rig setup leaves the Settings menu list. Settings › Rig gets a header while something is missing, and the header goes away once all four are done. Pick one:

2 · The Rig setup sheet: what each button fixes

Today the fix button and Not now use the same grey style. Whether the fix sits beside or under its text depends on the window width, so a button can look like it belongs to the line below it. In the proposal, each missing fact is its own amber box with its button inside. Done rows are flat with a tick. Not now becomes a quiet text button in a footer, next to a count.
