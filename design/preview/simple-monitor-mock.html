Ara Monitor

Monitor idea

A full-screen, read-only view of the imaging session for Simple Mode. The line on top says whether all is well; each tile is one thing about the night. Switch State to see how it reacts. All numbers are made-up examples, and the countdowns run live.

How you get there

A Monitor item on Simple Mode's left rail, beside Sky, Info and Library. The × comes back to the frame. The screen stays awake while it shows.

What it may do

It only reads. The one control is Emergency Stop, because that is on every screen. A tap on a tile opens the window or panel that already owns that thing, so nothing is built twice.

What stays above it

The full-screen safety alarm still covers everything. Unsafe here shows the screen after Silence. A question takes the top line, with its button (State: Question).

Only the gear you have

Tiles come from the rig's profile, and the others grow into the room (Rig: Small rig). Gear in the profile that drops mid-night stays on screen in red (State: Guider dropped), so a fault can't look like a tidy layout.
