Notes for the decision

• Plan is the plan sheet as today, but it only queues: Add to queue, then a green Next: Focus once one target is in. Nothing starts imaging here.
• Focus and Polar align work as today (a finished autofocus moves on; Polar align starts its routine on entry). Steps already done tonight are skipped, Polar align too on a permanent pier.
• A: a fourth step, Start: the queue squares show, the rail's shutter is the plan's ▶, and one tap starts imaging; Night Setup ends there. One more tap, but nothing starts by surprise, and the last check (clouds, the mask, the dew heater) happens before it.
• B: no fourth step: the last setup step's Done reads "Done · Start imaging" (Polar align's, or on a permanent pier the focus step's). One tap fewer.
• A scheduled start (Start at dark) still applies: the start waits on the rig as today.
